Privacy policy: Clip Vault uploader

Last updated 18 November 2026.

Who uses it

Only its owner, for the owner's own YouTube channel.

What it does with Google data

It uses YouTube API Services to upload the owner's videos to the owner's channel, to list that channel's own uploads, and to read back or delete a video it uploaded itself.

What it stores

One sign-in token for the owner's own Google account, kept on the owner's own server. Nothing else from Google is stored.

What it shares

Nothing. No data is sold, shared or sent to anyone. There are no analytics, cookies or ads, here or in the tool.

Other people's data

It collects none. It has no accounts for anyone else.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions.

YouTube and Google

This tool uses YouTube API Services. See YouTube's Terms of Service and Google's Privacy Policy.

This page

This page is hosted on GitHub Pages. GitHub may record technical details of visits, such as IP addresses, as its own privacy statement describes.

Contact

Through the channel GTA 6 Clip Vault on YouTube.
